# Flight Path Optimization (Matlab Code Implementation)

This project is based on a critical issue in the aviation industry: how to optimize aircraft trajectory and control to improve flight time and fuel consumption. The project aims to provide response elements to this problem and define the optimal response under certain simplifying assumptions. Model Predictive Control (MPC) will be used. Therefore, the first step will be to define the aircraft's dynamics model based on controllable inputs and wind disturbances. Finally, we will determine an exact objective for optimization and implement an optimization program to address it.
